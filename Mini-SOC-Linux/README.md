# Mini SOC Linux

## 🎯 Objectif

Construire progressivement un laboratoire personnel de cybersécurité
permettant de comprendre la collecte de logs, l'analyse réseau,
la détection et l'investigation d'activités suspectes.

## 🏗️ Environnement

- Linux
- Machines virtuelles
- Wireshark
- Python
- Bash
- SIEM (à intégrer progressivement)

## 🎯 Objectifs techniques

- Administration Linux
- Réseaux TCP/IP
- Analyse réseau
- Analyse de logs
- Détection d'activités suspectes
- Investigation
- Automatisation avec Python
- Utilisation d'un SIEM

## 📈 Progression

- [ ] Préparer l'environnement Linux
- [ ] Comprendre les interfaces et routes réseau
- [ ] Observer le trafic avec Wireshark
- [ ] Comprendre les logs Linux
- [ ] Analyser les événements SSH
- [ ] Créer des scénarios suspects dans le laboratoire
- [ ] Développer un script Python d'analyse
- [ ] Mettre en place des détections
- [ ] Intégrer un SIEM
- [ ] Documenter une investigation complète
